# Research sources — 2026-10-22 (spec v1.1: head motion and gestures)

These are the primary sources behind `SDD.md` §6.6, the v1.1 rows of §6.1 and the v1.1 entries in `models/registry.yaml`. Speeds are the authors' own figures, measured on their hardware. Items marked **unverified** are confirmed in spike S5 before any model is approved. Re-check every licence before relying on it.

## Findings that shaped the design
1. **No live generative option.** No released model with commercial-use code and weights generates upper-body video with hands within NFR-L3 (≤ 200 ms) on one GPU.
   - LiveAvatar: 45 fps at 720×400 on 5×H100, 1.21 s to first frame; 3.7–5 fps on one GPU, which needs ≥ 80 GB (FP8 fits 48 GB).
   - SoulX-LiveAct: 20 fps at 720×416 on 2×H100/H200. Its code repository has **no licence file**, so all rights are reserved.
   - StreamAvatar: 25 fps on 2×H800, about 1.2 s latency. Not released.
2. **Offline hand quality.** Wan2.2-S2V-14B is the only Apache-licensed model with published hand-quality figures: HKC 0.435, HKV 0.142.
   - InfiniteTalk (Apache-2.0) accepts a video as input.
   - Neither renders natively above 720p.
3. **Audio-to-gesture generators are blocked by licences.**
   - EMAGE, TalkSHOW, DiffSHEG and SynTalker output SMPL-X or FLAME bodies. SMPL-X and AMASS prohibit commercial use; a commercial licence is available via Meshcapade.
   - BEAT: the project page states a non-commercial licence, although the HF BEAT2 dataset is tagged apache-2.0. Treated as non-commercial until clarified.
   - Talking With Hands and Audio2Photoreal are CC-NC.
   - Exception: FLAME 2023 Open is CC BY 4.0 and allows commercial use.
4. **Gesture reenactment from footage.**
   - TANGO is CC BY-NC 4.0.
   - The original GVR repository contains only a README.
   - Adobe patent **US12347135B2** ("gesture reenactment video from video motion graphs") was granted 2025-07-01 and is active. Only the abstract was read, not the claims, so it goes to counsel (G1).
5. **Licences excluded outright.**
   - HunyuanVideo-Avatar: the Tencent Hunyuan Community License does not apply in the EU, UK or South Korea, needs Tencent approval above 100M monthly users, and forbids using outputs to improve other models.
   - Hallo3: needs InsightFace models.
   - EchoMimicV2 weights: "intended for academic research", with no licence tag.
   - AVTR-1: reportedly free only below $10M annual revenue (secondary source, **unverified**).
6. **Banned-component traces in candidates.**
   - LiveAvatar's `requirements.txt` installs `insightface`. `liveavatar/utils/router/sam2_tools.py` calls `FaceAnalysis`, on the multi-speaker path only.
   - EchoMimicV3 uses the `retina-face` package; where its weights come from is **unverified**.
   - StableAvatar's training masks come via StableAnimator, which needs `insightface` (training only).

## Metrics (NFR-Q6, NFR-Q7)

| Metric | Defined in | Computed with |
|---|---|---|
| Beat Alignment Score | AI Choreographer (arXiv 2101.08779); used for gestures in BEAT (2203.05297) and for head motion in SadTalker (2211.12194) | Onsets from librosa plus a pose track. Kernel width σ differs between papers, so S5 fixes one value |
| Head-pose variation (std of yaw, pitch, roll) | SadTalker supplement; Hopenet (arXiv 1710.00925) | MediaPipe Face Landmarker pose matrix (Apache). Hopenet weights come from 300W-LP, which is built by 3DMM fitting, so check against the BFM ban (**unverified**) |
| HKC / HKV | CyberHost (arXiv 2409.01876); reported by EchoMimicV2 and Wan-S2V | DWPose (Apache code; weights tagged Apache; training-data terms **unverified**), RTMW, or MediaPipe Hand Landmarker. Never OpenPose (non-commercial) |
| Sync-C / Sync-D | Wav2Lip (arXiv 2008.10010) | syncnet_python (code MIT; weights licence **unverified**) |
| CSIM | CyberHost and others | ArcFace via InsightFace, which is **banned**. Visavox uses AuraFace similarity (NFR-Q4) instead |
